# FieldShift Research Institute
## Brand Identity System — Reference Document
**Version 1.0 | 2025**

---

## 1. Brand Overview

**FieldShift Research Institute** is a scientific research organization advancing state-based science across complex systems. The brand identity must convey the same qualities as the institution's work: rigor, precision, intellectual seriousness, and timeless credibility. The visual language draws on the traditions of IAS Princeton, Santa Fe Institute, MIT, and Oxford — institutions whose identities feel equally at home on a century-old letterhead and a modern dashboard.

The brand avoids: startup hype, cyberpunk, crypto iconography, military aesthetics, overly futuristic aesthetics, gradient-heavy decoration, and any visual language that would embarrass a researcher presenting at an academic conference.

---

## 2. Mission, Vision, and Voice

**Mission:** To advance the science of state — the rigorous study of how systems occupy, transition between, and are characterized by their states.

**Vision:** A world in which complex systems — democratic, biological, computational, financial — are understood, monitored, and governed through the lens of their underlying state dynamics.

**Research focus:**
- Fractal State Theory (FST) and state-based inference
- Observer theory and state-dependent measurement
- Early warning systems for democratic fragility and state transitions
- AI systems through a state-theoretic lens
- Complex systems: biological, financial, computational, social

**Voice:** Authoritative, precise, dry, understated. Statements of fact, not aspiration. Avoids superlatives, hype, and marketing register. Writes as a scientist writes.

### 3.5 Prohibited Alterations

Do not:
- Recolor the wordmark in any color other than the approved palette
- Separate "Field" from "Shift" in the wordmark
- Scale the symbol independently of the wordmark
- Add drop shadows, glows, or outer strokes to the logo
- Place the full logo at sizes below the minimum clear-space requirement
- Rotate the logo
- Use the logo on backgrounds with insufficient contrast (minimum 4.5:1 ratio)

## 4. Symbol (The Hexagon Mark)

### 4.1 Conceptual meaning

The FieldShift symbol is a layered geometric mark encoding the institute's core scientific concepts:

**Outer hexagon (flat-top):** The bounded system — a state space with defined structure. Hexagonal geometry is found throughout nature (crystal lattices, biological tissue, honeycomb), suggesting the universal applicability of state-based science. The flat-top orientation gives stability and weight.

**Inner hexagon (pointy-top, rotated 30°, lower opacity):** Nested state space — a system within a system. The rotation encodes transformation; the reduced opacity suggests an underlying or latent structure, not immediately visible to the observer.

**Radial spokes (three, to alternating vertices):** State transition graph — the network of possible transitions between discrete states. Three spokes rather than six preserve visual openness while suggesting connectivity.

**Threshold polyline (horizontal step-function):** The FieldShift signature — a horizontal baseline that rises sharply through a central step. This represents: state transition (the moment a system crosses a threshold), field shift (regime change), the fundamental phenomenon the institute studies. The step is the scientific event at the heart of all FST research.

**Observer dot (filled circle at inflection point):** The observer — a point within or watching the system. The small halo ring around it suggests a lens, an eye, or a measurement instrument. Position at the inflection point signals that observation must be state-aware: the observer must know where in the system's trajectory they are measuring.

### 4.2 Symbol-only usage

File: `/assets/icon/fieldshift-icon.svg`

Use the symbol alone (without wordmark) only when the FieldShift brand is already established in context — e.g., within an app interface after the user has signed in, as a watermark on internal presentations, or as a repeated decorative element.

Never use the symbol alone as a first-impression or external-facing primary identifier without the wordmark nearby.

## 5. Academic Seal

File: `/assets/seal/fieldshift-seal.svg`

The seal is for formal institutional use: diplomas, certificates, faculty appointment letters, legal documents, official correspondence, official publications. It follows the tradition of university seals — circular form, text around the ring, institutional mark at center.

**Ring text (outer):** FIELDSHIFT RESEARCH INSTITUTE  
**Ring text (inner, italic):** Advancing the Science of State  
**Bottom text:** EST. MMXXV  
**Center:** The hexagon mark

The seal should not be used as a substitute for the logo in standard communications. It connotes official, formal, or ceremonial weight.


### 7.2 Type Scale (Major Third, 1.25×)

| Token | Size | Use |
|-------|------|-----|
| `--text-4xl` | ~61px | Display / hero headline |
| `--text-3xl` | ~49px | H1 — Section title |
| `--text-2xl` | ~39px | H2 — Subsection |
| `--text-xl`  | ~31px | H3 — Sub-subsection |
| `--text-lg`  | ~25px | H4 — Card title |
| `--text-md`  | ~20px | H5 / Intro paragraph |
| `--text-base`| 16px  | Body text |
| `--text-sm`  | ~13px | Captions, metadata |
| `--text-xs`  | ~10px | Labels, micro-copy, badge text |

### 7.3 Typography Rules

- **Headings** use `font-family: var(--font-serif)`, color `var(--text-primary)`, `letter-spacing: var(--tracking-tight)` at display sizes.
- **Body** uses `font-family: var(--font-sans)`, `line-height: var(--leading-normal)` (1.6).
- **Captions, metadata, data labels** use `font-family: var(--font-mono)`, `font-size: var(--text-xs)`, `letter-spacing: var(--tracking-wider)`, `text-transform: uppercase`.
- **Pull quotes and italic emphasis** use `Libre Baskerville Italic`, generous leading (1.75+), left border in gold.
- **Never** use bold Libre Baskerville for body text. Bold weight is reserved for headings and the wordmark.
- **Paper context:** For academic PDFs, defer to LaTeX defaults (Latin Modern); do not attempt to replicate the web typeface stack in LaTeX. The PDF identity is established through the header/logo placement, not the body typeface.

### 9.2 Rules

- Never use the motto as a headline in gold — it is a secondary, scholarly element.

## 10. Figure and Diagram Style

### 10.1 Research figures (charts, graphs, state diagrams)

- Background: white (`#ffffff`) or paper (`#f9f6f1`) for print; dark navy (`#0d2247`) for slides
- Grid lines: `#e8e4de` (light mode) or `rgba(255,255,255,0.08)` (dark mode) — subtle, not dominant
- Axis labels: Source Sans 3, 11–12px, `#4a4a4a`
- Figure captions: italic, 11px, `#7a7a7a`, below figure, left-aligned
- Color series: use the scientific accent palette — teal, sage, terracotta, slate, gold
- Threshold / critical state lines: gold (`#b8922a`), dashed, labeled in italic serif
- Annotation text: JetBrains Mono, small, `#4a4a4a`

### 10.2 Avoid in figures

- 3D effects on 2D data
- Pie charts (use bar or area charts)
- Drop shadows on chart elements
- Saturated rainbow color series
- Chartjunk (decorative gridlines, redundant legend boxes)

## 11. Publication Design

### 11.1 Academic papers (PDF)

- Header: FieldShift logo (mono-black variant) top-left; volume/issue info top-right in JetBrains Mono
- Font stack: Latin Modern (via LaTeX) or Libre Baskerville / Source Sans 3 (web PDF)
- Abstract box: light gold tint (`#fbf5e0`) background, gold left border, no rounded corners
- Section headers: Libre Baskerville Bold, numbered, full-width, 2px gold underline rule
- Footnotes: Source Sans 3, 9pt, `#4a4a4a`
- DOI / metadata line: JetBrains Mono, 9pt, `#7a7a7a`
- Page margin: 25mm all sides; header/footer in page margin zone
- Do not use drop caps except in the opening paragraph of major reports

### 11.2 Working papers and reports

- Cover: Dark navy background, stacked logo (white variant) centered, title in Libre Baskerville 32pt+ white, author list in Source Sans 3 14pt pale
- Inside pages: paper background, black text, gold section rules
- Headers: logo small, top-right, mono-black variant (on white pages)

### 11.3 Presentations (slides)

- Title slide: full navy background, stacked logo, title large serif white, subtitle mono-light
- Content slides: paper background, heading in navy serif, body in sans
- Data slides: dark navy background, figures with dark theme (white axes, gold threshold lines)
- Footer: logo mark (symbol only), slide number in mono, institute name small
- Do not use PowerPoint default themes. Build from these specs.

## 12. Website and App UI

### 12.1 Masthead

- Background: `--brand-navy` (`#0d2247`)
- Bottom border: 3px solid `--brand-gold` (`#b8922a`)
- Logo: horizontal primary variant (SVG, not PNG unless performance demands it)
- Navigation: Source Sans 3, 13px, spaced caps, `--color-paper-4`; hover in `--brand-gold-light`

### 12.2 Page structure

- Max content width: 1400px
- Body background: `--surface-canvas` (`#f9f6f1`)
- Section rules: 2px solid `--border-strong`, not gold (gold rules are accent elements, not structural separators)
- Cards/panels: white background, 1px `--border-subtle`, no border-radius by default (or 2px maximum)
- Serif headings for section titles; sans for navigation, labels, UI chrome

### 12.3 Dashboard / data application

- Maintain the existing color variable system (already established in index.html)
- Status indicators use the FSI status palette (danger/warn/ok/info)
- Metric cards: paper background, serif number (large, navy), sans label (small, secondary ink)
- Charts follow the figure style guide (section 10)

### 12.4 Dark mode

- Use `data-theme="dark"` attribute or `prefers-color-scheme: dark`
- All semantic tokens automatically update via CSS; do not hardcode colors in component CSS
- Dark mode background: `#0a0f1a` (deeper than primary navy, prevents eye strain)

## 14. Do / Don't Reference

| Do | Don't |
|----|-------|
| Use Libre Baskerville for headlines | Use Impact, Futura, or sans-only for headline |
| Maintain navy/gold palette | Introduce brand-new accent colors for UI chrome |
| Use the observer dot at inflection | Reposition or remove the observer dot |
| Keep the step-function as a horizontal rise | Make it look like a lightning bolt or zigzag |
| Use flat color mark when in doubt | Default to gradient version everywhere |
| Choose muted teal/sage for chart series | Use saturated primary colors (R/G/B at full chroma) |
| Place logo on dark navy or paper backgrounds | Place logo on brights (red, lime, orange) |
| Maintain minimum clear space | Crowd the logo with other text or icons |
| Use the seal for formal/ceremonial documents | Use the seal as a general logo substitute |
| Use JetBrains Mono for data/metadata | Use Courier New or Times New Roman for code |

## 15. File Naming and Export Specifications

### 15.1 Asset file naming convention

```
fieldshift-[asset-type]-[variant]-[colormode].[ext]
```

Examples:
- `fieldshift-logo-primary.svg` — horizontal, full color
- `fieldshift-logo-stacked.svg` — vertical, full color
- `fieldshift-logo-mono-black.svg` — mono, black on white
- `fieldshift-logo-mono-white.svg` — mono, white, no bg
- `fieldshift-icon.svg` — symbol mark 100×100
- `fieldshift-favicon.svg` — favicon 32×32
- `fieldshift-social.svg` — social profile 400×400
- `fieldshift-seal.svg` — academic circular seal

### 15.2 Export specifications by context

| Context | Format | Size | Notes |
|---------|--------|------|-------|
| Web / app | SVG | (native viewBox) | Primary format — always prefer SVG |
| Web fallback | PNG @2x | 2× intended display size | For SVG-unsupported contexts |
| Favicon | ICO + SVG | 16, 32, 48px (ICO); 32×32 (SVG) | ICO for legacy browsers |
| Social profile | PNG | 400×400 @2x = 800×800px export | No transparency on social |
| Print (letterhead) | PDF or EPS | 100mm wide minimum | Embed fonts; no raster at print |
| Print (seal) | PDF | 60mm diameter minimum | At 60mm+, all text remains legible |
| Embroidery | PNG | 300dpi at final emb. size | Simplify inner hex and spokes |
| LaTeX | PDF (logo-only page, cropped) | — | Use `\includegraphics` |

### 15.3 Color modes by context

| Background | Logo variant |
|------------|-------------|
| Dark navy (`#0d2247`) | Primary (full color) |
| Mid navy (`#1a3a6b`) | Primary or mono-white |
| Paper / white | Mono-black |
| Colored (any) | Mono-black (light BG) or mono-white (dark BG) |
| Projection / slide dark | Primary or mono-white |
| Newspaper / B&W print | Mono-black |
