CDRS with V-Dem v16: recipe v2 and recalibration (2026-11-26)

Status: since v0.9.0, the dashboard uses recipe v2 (2010–2025) and the recalibrated thresholds below. The sections further down on the original recipe (v1) describe the previous step.

Recipe v2 (Method Box of the JoD manuscript) – used in the dashboard from v0.9.0

The build is done by build_cdrs_v2.py, and the source files are in sources/raw/.

LayerIndicators (stress, fixed scales)
FiscalSIPRI military expenditure/government expenditure (x/20 %), IMF budget balance (−balance/10 %), IMF gross debt (x/150 % of GDP)
ConstitutionalV-Dem 1 − v2x_jucon; CCP new constitutions, interim constitutions and suspensions t−4…t (/2)
OrganizationalV-Dem 1 − v2x_cspart; IDEA 1 − free_parties_est; IDEA 1 − cred_elect_est
NormsFreedom House ((PR + CL)/2 − 1)/6; RSF 1 − score/100 (index N = year N−1)
ResilienceWGI (2.5 − GE)/5 and (2.5 − RL)/5; SIPRI military expenditure/GDP (x/8 %)
CDRSMean of the layers if at least three layers are available

Source versions:

  • V-Dem v16, IDEA GSoD v10 (2026-06), Freedom House ratings 1973–2024 (FIW 2025), RSF index 2013–2026, CCP Chronology v6, SIPRI Milex 1949–2025 and IMF DataMapper (WEO), retrieved 2026-11-26.
  • WGI from the World Bank (2026-09).

Assumptions and deviations:

  • Freedom House for 2025 is carried forward from 2024.
  • RSF is missing before 2012. Without RSF, the Norms layer is on average 0.03 higher, which corresponds to less than 0.01 in CDRS.
  • The IMF values for 2025 are estimates.
  • IMF GFS is replaced by IMF WEO (DataMapper).
  • To protect FS-004, only v2x_jucon and v2x_cspart are read from V-Dem for 2010–2022.

Recalibration (calibrate_v2.py, 2026-11-26)

  • Calibration: democratic country-years 1996–2006 (v2x_regime 2 or 3). The outcome is a transition to autocracy within 3 years, up to and including 2009. No outcomes from the FS-004 reserved period 2010–2022 are used.
  • Basis: 932 country-years, 57 windows with a transition and 99 countries. AUC 0.816.
  • Warning threshold W = 0.263 (95% CI 0.248–0.316). This is the Youden optimum, with sensitivity 0.912 and specificity 0.649.
  • Lead-time threshold c_L = 0.214 (95% CI 0.175–0.275). This is the highest threshold with sensitivity ≥ 0.95.
  • Risk bands: a logistic model, P = 1/(1 + e^−(-6.249 + 12.441·CDRS)), gives the band limits:

| Limit (3-year risk) | CDRS | 95% CI |

|---|---|---|

| 1 % | 0.133 | 0.04–0.205 |

| 2 % | 0.189 | 0.118–0.247 |

| 5 % | 0.266 | 0.218–0.318 |

| 10 % | 0.326 | 0.287–0.383 |

| 20 % | 0.391 | 0.35–0.466 |

The dashboard uses the rounded limits 0.13 / 0.19 / 0.26 / 0.33 / 0.39.

  • Out-of-sample test: 88 democracies in 2023, of which 7 became autocracies in 2024–2025 (ALB, BIH, GEO, MEX, ZMB, IDN, MNG). AUC 0.8. At W, 7 of 7 transitions are captured, with specificity 0.531.
  • Limitations:
  • The windows overlap, so 57 windows correspond to about 20 episodes.
  • The test is based on only 7 events.
  • The probabilities apply to democracies; for autocracies they have no interpretation.
  • The 28 red-flag indicators (quantile matching, results/rfs_trosklar_v2.json) and the 24 country analyses (results/landanalyser_v2.json) have been recalculated in dashboard v0.10.0.
  • The observed line in the election chart is based on Freedom House subscore A (build_fh_electoral.py, results/fh_electoral_process.json).

The previous step: original recipe v1 (2026-11-25)

What was done

  • The recipe: source/fieldshift_loader_original_2026-02-28.py was retrieved from Drive. It is the only script found that produces the dashboard's five layers and source labels. The file was not run. The country list and indicators were extracted with AST, and the recipe is followed verbatim in build_cdrs_v16.py.
  • Data:
  • V-Dem v16 (V-Dem-CY-Full+Others-v16.csv): only country_text_id, year, v2x_jucon, v2x_cspart and v2x_libdem were read.
  • World Bank WGI (API source 3, new codes GOV_WGI_*, updated 2026-09-25) and WDI (military and education expenditure, updated 2026-11-11), 2010–2025: data/worldbank_2010_2025.json.
  • FS-004: V-Dem 2010–2022 was read under Thomas's decision of 2026-11-25 ("Ja, bara för dashboarden") ("Yes, only for the dashboard"). It applies only to the dashboard's descriptive layers. Nothing here may be used in FS-004.
  • Results:
  • results/countries_v16_2010_2023.json: the same period as the dashboard, for comparison.
  • results/countries_v16_2010_2025.json: updated up to and including 2025.

Both files have the same format as the dashboard's countries.json: 163 available countries and 6 unavailable.

The recipe (fieldshift_loader.py)

The World Bank values are min-max normalized per indicator across all units and years that the API returns, including regional aggregates. This is a weakness in the original, and it is kept here.

Deviations from the original:

  • Freedom House is not available locally. The source is used only when V-Dem is missing.
  • Taiwan has been added, because the dashboard includes it. It is based on V-Dem only.
  • SIPRI, IMF, RSF, CCP and IDEA are not used in the original calculation either.

Assessment

  • The recipe does not reproduce the current values. The ranking is similar to the current one (r = 0.88), but the levels differ a lot for individual countries. The Fiscal layer has in practice no relationship with the current values (r = 0.12).
  • The current countries.json has features that do not arise from the recipe:
  • two decimals;
  • 3–9 years per country (usually 4) instead of all years;
  • even steps, for example Sweden's Fiscal layer 0.11 → 0.12 → 0.14 → 0.17 → 0.20.

The origin of the current values is therefore unclear. They may have been processed or compiled in a different way than with this recipe. This cannot be determined from the material found so far.

  • Consequences for what builds on the current values:
  • Table 1 of the JoD manuscript and its statistics (Cohen d, 86.7 %, AUC 0.96);
  • the warning threshold 0.52 and the lead-time threshold c_L ≈ 0.22;
  • A3, A4 and A6 in the calculator.

None of this can be transferred to the v16 values without new calibration and validation.

Decisions needed

  • Whether the dashboard should switch to the reconstructed v16 values, as a new version with new calibration, or keep the current values with a clear provenance label.
  • Whether the original step that produced the current values should be traced, and if so, where.
