Matematisk definition av Hedlund-Leijon-principen och CDRS-modellen

Utarbetad som en renodlad teknisk anteckning med helt standardiserad matematisk notation

Detta dokument ger en strikt matematisk formulering av ℋ = 1.724 och en formaliserad modell av Composite Democratic Risk Score (CDRS). Notationen nedan är standardiserad för direkt användning i en teknisk artikel, en metodbilaga eller en matematisk anteckning.

1. Matematisk modell för ℋ = 1.724

Låt D(c,t) beteckna demokratinivån i land c vid tidpunkt t.

Definitioner av episoder

För varje erosionsepisod e i land c, från start t_{e,0} till slut t_{e,1}, definieras erosionens storlek som

Me− = Dc,te,0 − Dc,te,1, Me− > 0

För varje återhämtningsepisod r i land c, från start t_{r,0} till slut t_{r,1}, definieras återhämtningens storlek som

Mr+ = Dc,tr,1 − Dc,tr,0, Mr+ > 0

Kärndefinition av Hedlund-Leijon-principen

Den empiriska asymmetrin definieras som kvoten mellan den genomsnittliga storleken på demokratisk återhämtning och den genomsnittliga storleken på demokratisk erosion:

ℋ = [ (1/R) Σ r=1R Mr+ ] / [ (1/E) Σ e=1E Me− ]

där R är antalet återhämtningsepisoder och E är antalet erosionsepisoder.

I den empiriska skattningen blir detta:

ℋ = 109.4 / 63.5 ≈ 1.724

Tolkning: för varje 1 enhet demokrati som går förlorad genom erosion kräver demokratisk återhämtning i genomsnitt 1,724 enheter av kumulativ återställande rörelse.

Bootstrapskattare av ℋ

Eftersom ℋ är bootstrapvaliderad kan skattaren för bootstrapdragning b = 1, …, B med B = 10,000 skrivas som

ℋ̂(b) = [ (1/Rb) Σ r=1Rb Mr+,(b) ] / [ (1/Eb) Σ e=1Eb Me−,(b) ]

Den slutliga skattningen blir då

ℋ̂ = median(ℋ̂(1), …, ℋ̂(B)) = 1.724

CI95%(ℋ) = [1.53, 1.96]

Kritisk gräns

Den kritiska gränsen definieras som

κ = ℋ / 8

κ = 1.724 / 8 = 0.2155 ≈ 0.216

Detta är det samband för varningsgränsen som används i modellen.

Illustrativ dynamisk framställning

En stiliserad dynamisk form som är förenlig med manuskriptet kan skrivas som

D(t) = Deq + A0 e−δt sin(ℋ·t/T + φ)

där D_eq är demokratins jämviktsnivå, A_0 är den initiala amplituden, δ är en parameter för dämpning eller institutionell tröghet, T är den karakteristiska cykellängden och φ är fasförskjutningen. Ekvationen bör i första hand tolkas som en illustrativ dynamisk framställning och inte som den primära skattaren av ℋ. Den primära matematiska definitionen av ℋ är fortfarande asymmetrikvoten mellan kumulativ återhämtning och kumulativ erosion.

2. Matematisk modell för CDRS

Låt CDRS(c,t) beteckna Composite Democratic Risk Score för land c vid tidpunkt t. Den definieras som ett sammansatt mått på demokratisk stress, med

CDRSc,t ∈ [0, 1]

där högre värden anger större demokratisk stress och större demokratisk risk.

Femdimensionell struktur

Låt de fem komponentdimensionerna definieras enligt följande:

Fc,t = finanspolitisk integritetsstress

Cc,t = konstitutionell begränsningsstress

Oc,t = organisatorisk konkurrensstress

Nc,t = stress i demokratiska normer

Rc,t = stress i institutionell motståndskraft

Varje dimension normaliseras till intervallet [0, 1], där 0 betecknar låg stress och 1 betecknar högsta observerade stress.

Grundformulering med lika vikter

Om huvudmodellen använder lika vikter är definitionen av CDRS

CDRSc,t = (1/5)(Fc,t + Cc,t + Oc,t + Nc,t + Rc,t)

Detta är den tydligaste huvudekvationen för CDRS i den tekniska artikeln.

Allmän viktad formulering

Mer allmänt kan modellen skrivas som

CDRSc,t = Σ j=15 wj Xj,c,t

Σ j=15 wj = 1

och i grundspecifikationen är w_j = 0.2 för alla j.

Normalisering av komponentindikatorer

Om en rå indikator skrivs som Z(j,c,t) definieras min-max-normalisering som

Xj,c,t = (Zj,c,t − min(Zj)) / (max(Zj) − min(Zj))

när högre råvärden innebär större demokratisk stress. Om en rå indikator i stället anger starkare demokratisk prestation snarare än stress är den normaliserade stressversionen

Xj,c,tstress = 1 − (Zj,c,t − min(Zj)) / (max(Zj) − min(Zj))

Detta ger alla komponenter samma riktning: högre värden anger alltid svårare demokratisk stress.

Fullständig sammansatt modell

Den fullständiga sammansatta formen kan därför skrivas som

CDRSc,t = (1/5)[ F̃c,t + C̃c,t + Õc,t + Ñc,t + R̃c,t ]

där varje term med tilde betecknar en normaliserad stresskomponent i intervallet [0, 1].

Gränsregim för CDRS

Gränsregimen för CDRS definieras av κ enligt följande:

CDRSc,t < κ ⇒ stabil zon / zon med låg stress

CDRSc,t ≥ κ ⇒ varningszon / förhöjd demokratisk stress

κ = 0.216

Detta är den renaste gränsregeln för modellen.

Valfritt dynamiskt riskskikt ovanpå CDRS

Om man vill modellera tanken att demokratisk stress blir farligare efter κ kan en accelerationsterm läggas till:

Ac,t = max(0, (CDRSc,t − κ) / (1 − κ))

Om CDRS(c,t) < κ finns då ingen term för accelererad risk; om CDRS(c,t) ≥ κ växer riskaccelerationen gradvis mot 1.

Ett jämnare alternativ är en logistisk riskfunktion:

P(collapsec,t+h) = 1 / (1 + exp[−α(CDRSc,t − κ)])

där α styr hur brant risken ökar och h är prognoshorisonten. Denna utvidgning är användbar om modellen senare förs över från ett stressindex till uttrycklig sannolikhetsprognos.

3. Rekommenderad formulering för teknisk artikel

Den mest koncisa och publiceringsfärdiga formuleringen är följande:

ℋ = [(1/R) Σ Mᵣ⁺] / [(1/E) Σ Mₑ⁻] = 1.724

κ = ℋ / 8 = 0.216

CDRS(c,t) = (1/5)(F(c,t) + C(c,t) + O(c,t) + N(c,t) + R(c,t))

där Mᵣ⁺ betecknar den kumulativa storleken på den demokratiska återhämtningsepisoden r, Mₑ⁻ betecknar den kumulativa storleken på den demokratiska erosionsepisoden e, och varje komponent i CDRS är normaliserad till enhetsintervallet och orienterad så att högre värden anger större demokratisk stress.

4. Rekommenderad användning i hela manuskriptet

Huvudtext: använd endast de tre mest kompakta uttrycken.

  • ℋ = M⁺ / M⁻ = 1.724
  • κ = ℋ / 8 = 0.216
  • CDRS = (1/5)(F + C + O + N + R)

Metodbilaga: ta med de exakta episoddefinitionerna, normaliseringsregeln, bootstrapskattaren och eventuellt det valfria logistiska riskskiktet.

Figurtexter: använd kortfattade formuleringar som ”högre CDRS anger större demokratisk stress” och ”κ markerar början på förhöjd systemisk skörhet”.

5. Teknisk text (i originalet på engelska) klar för direkt användning

Följande stycke kan infogas direkt i den tekniska artikeln:

Hedlund-Leijon-principen definieras som den empiriska asymmetrin mellan den genomsnittliga storleken på demokratisk återhämtning och den genomsnittliga storleken på demokratisk erosion. I kompakt form är ℋ = 1.724 och den motsvarande kritiska gränsen är κ = ℋ/8 = 0.216. Composite Democratic Risk Score definieras som ett femdimensionellt stressindex med lika vikter, CDRS(c,t) = (1/5)(F + C + O + N + R), där varje komponent är normaliserad till [0,1] och orienterad så att högre värden anger större demokratisk stress. Att gränsen κ passeras identifierar förhöjd systemisk skörhet snarare än deterministisk kollaps.
