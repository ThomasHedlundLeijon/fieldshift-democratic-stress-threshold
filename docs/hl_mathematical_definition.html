Mathematical Definition of the Hedlund-Leijon Principle and the CDRS Model

Correction (26 November 2026). In FieldShift, κ = ℋ/8 ≈ 0.216 is a threshold on the democracy level D (D ≤ κ), not on the CDRS scale. Under CDRS ≈ 1 − D it corresponds to CDRS ≈ 0.78. The thresholds used on the CDRS scale are empirical: the lead-time threshold cL = 0.21 and the warning threshold W = 0.26, calibrated on regime transitions 1996–2009 (data series v2). The statements below that apply κ directly to CDRS are kept as in the source document but do not hold. Details: the HL calculator, propositions S3, S8 and S18.

Prepared as a clean technical note with fully standardized mathematical notation

This document presents a strict mathematical formulation of ℋ = 1.724 and a formalized model of the Composite Democratic Risk Score (CDRS). The notation below is standardized for direct use in a technical paper, methods appendix, or mathematical note.

1. Mathematical Model for ℋ = 1.724

Let D(c,t) denote the level of democracy in country c at time t.

Episode definitions

For each erosion episode e in country c, from start t_{e,0} to end t_{e,1}, define the erosion magnitude as

Me− = Dc,te,0 − Dc,te,1, Me− > 0

For each recovery episode r in country c, from start t_{r,0} to end t_{r,1}, define the recovery magnitude as

Mr+ = Dc,tr,1 − Dc,tr,0, Mr+ > 0

Core definition of the Hedlund-Leijon Principle

The empirical asymmetry is defined as the ratio between the average magnitude of democratic recovery and the average magnitude of democratic erosion:

ℋ = [ (1/R) Σ r=1R Mr+ ] / [ (1/E) Σ e=1E Me− ]

where R is the number of recovery episodes and E is the number of erosion episodes.

In the empirical estimate, this becomes:

ℋ = 109.4 / 63.5 ≈ 1.724

Interpretation: for every 1 unit of democracy lost in erosion, democratic recovery requires, on average, 1.724 units of cumulative restorative movement.

Bootstrap estimator of ℋ

Because ℋ is bootstrap-validated, the estimator for bootstrap draw b = 1, …, B with B = 10,000 can be written as

ℋ̂(b) = [ (1/Rb) Σ r=1Rb Mr+,(b) ] / [ (1/Eb) Σ e=1Eb Me−,(b) ]

The final estimate is then

ℋ̂ = median(ℋ̂(1), …, ℋ̂(B)) = 1.724

CI95%(ℋ) = [1.53, 1.96]

Critical threshold

The critical threshold is defined as

κ = ℋ / 8

κ = 1.724 / 8 = 0.2155 ≈ 0.216

This is the warning-threshold relation used in the model.Correction: κ applies to the democracy level, not CDRS

Illustrative dynamic representation

A stylized dynamic form consistent with the manuscript can be written as

D(t) = Deq + A0 e−δt sin(ℋ·t/T + φ)

where D_eq is the equilibrium level of democracy, A_0 is the initial amplitude, δ is a damping or institutional inertia parameter, T is the characteristic cycle length, and φ is the phase shift. This equation is best interpreted as an illustrative dynamic representation rather than the primary estimator of ℋ. The primary mathematical definition of ℋ remains the asymmetry ratio between cumulative recovery and cumulative erosion.

2. Mathematical Model for CDRS

Let CDRS(c,t) denote the Composite Democratic Risk Score for country c at time t. It is defined as a composite measure of democratic stress, with

CDRSc,t ∈ [0, 1]

where higher values indicate greater democratic stress and greater democratic risk.

Five-dimensional structure

Let the five component dimensions be defined as follows:

Fc,t = fiscal integrity stress

Cc,t = constitutional constraint stress

Oc,t = organizational competition stress

Nc,t = democratic norms stress

Rc,t = institutional resilience stress

Each dimension is normalized to the interval [0, 1], where 0 denotes low stress and 1 denotes maximal observed stress.

Baseline equally weighted formulation

If the main model uses equal weights, the CDRS definition is

CDRSc,t = (1/5)(Fc,t + Cc,t + Oc,t + Nc,t + Rc,t)

This is the clearest main equation for CDRS in the technical paper.

General weighted formulation

More generally, the model can be written as

CDRSc,t = Σ j=15 wj Xj,c,t

Σ j=15 wj = 1

and in the baseline specification, w_j = 0.2 for all j.

Normalization of component indicators

If a raw indicator is written as Z(j,c,t), min-max normalization is defined as

Xj,c,t = (Zj,c,t − min(Zj)) / (max(Zj) − min(Zj))

when higher raw values imply greater democratic stress. If a raw indicator instead implies stronger democratic performance rather than stress, the normalized stress version is

Xj,c,tstress = 1 − (Zj,c,t − min(Zj)) / (max(Zj) − min(Zj))

This ensures common directionality across all components: higher values always indicate worse democratic stress.

Full composite model

The full composite form can therefore be written as

CDRSc,t = (1/5)[ F̃c,t + C̃c,t + Õc,t + Ñc,t + R̃c,t ]

where each tilde-marked term denotes a normalized stress component in the interval [0, 1].

Threshold regime for CDRS

The CDRS threshold regime is defined by κ as follows:Correction: κ applies to the democracy level, not CDRS

CDRSc,t < κ ⇒ stable / low-stress zone

CDRSc,t ≥ κ ⇒ warning zone / elevated democratic stress

κ = 0.216

This is the cleanest threshold rule for the model.

Optional dynamic risk layer above CDRS

If one wishes to model the idea that democratic stress becomes more dangerous after κ, an acceleration term can be added:

Ac,t = max(0, (CDRSc,t − κ) / (1 − κ))

Then, if CDRS(c,t) < κ, there is no accelerated risk term; if CDRS(c,t) ≥ κ, risk acceleration grows gradually toward 1.Correction: κ applies to the democracy level, not CDRS

A smoother alternative is a logistic risk function:

P(collapsec,t+h) = 1 / (1 + exp[−α(CDRSc,t − κ)])

where α governs how steeply risk increases and h is the forecast horizon. This extension is useful if the model is later moved from a stress index to explicit probabilistic prediction.

3. Recommended Technical-Paper Formulation

The most concise and publication-ready formulation is the following:

ℋ = [(1/R) Σ Mᵣ⁺] / [(1/E) Σ Mₑ⁻] = 1.724

κ = ℋ / 8 = 0.216

CDRS(c,t) = (1/5)(F(c,t) + C(c,t) + O(c,t) + N(c,t) + R(c,t))

where Mᵣ⁺ denotes the cumulative magnitude of democratic recovery episode r, Mₑ⁻ denotes the cumulative magnitude of democratic erosion episode e, and each component of CDRS is normalized to the unit interval and oriented so that higher values indicate greater democratic stress.

The following paragraph can be inserted directly into the technical paper:

The Hedlund-Leijon Principle is defined as the empirical asymmetry between the average magnitude of democratic recovery and the average magnitude of democratic erosion. In compact form, ℋ = 1.724 and the corresponding critical threshold is κ = ℋ/8 = 0.216. The Composite Democratic Risk Score is defined as an equally weighted five-dimensional stress index, CDRS(c,t) = (1/5)(F + C + O + N + R), with each component normalized to [0,1] and oriented so that higher values indicate greater democratic stress. Threshold crossing at κ identifies elevated systemic fragility rather than deterministic collapse.
